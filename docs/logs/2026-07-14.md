# 2026-07-14 (화) — 핵심 가설을 더 작고 선명하게 만들기

## Q. 해결하고 싶은 불편 1개

주차 기록을 입력하는 과정 자체도 불편하지만, 주차가 끝난
시점에 주차 기록을 위해 서비스에 접근하는 과정 또한 번거롭고,
까먹을 가능성이 높다.

## Q. 가설/가정 (한 문장)

사용자가 운전을 끝낸 시점에 자동으로 주차 위치를 기록할 것인지
물어보는 알림 기능을 구현하면 접근성을 더 높일 수 있을 것이다.

## 한 일

- 가상 센서 조작판으로 운전 시작 → 블루투스 연결 → 주행 종료(걷기
  전환)를 시뮬레이션하는 UI 구현
- 차량 블루투스 연결 해제 + 걷기 상태 전환 시, 또는 블루투스 등록
  없이 운전→걷기로 전환될 때 자동으로 "지금 기록하기" 푸시 알림이
  뜨도록 구현
- 설정 화면에 자동 감지 on/off, 차량 블루투스 기기 등록 기능 추가

## 상태

- 기능은 프로토타입 상에서 얼추 구현 완료.
- **아직 사용자 피드백은 받지 못함.**

## 다음에 확인할 것

- 이 자동 감지 알림 흐름을 사용자에게 보여주고, 실제로 접근성
  문제를 줄여주는지, 오히려 불필요한 알림으로 느껴지진 않는지
  물어본다.
