# 2026-07-15 (수) — 사용자에게 더 잘 묻기

## Q. 해결하고 싶은 불편 1개

지금까지의 흐름은 여전히 사용자가 직접 여러 항목(층/구역/사진/메모)을
입력해야 기록이 완성됐고, 블루투스 등록 같은 부가 절차도 있었다.
또한 "모든 주차장"을 대상으로 삼다 보니 지하주차장처럼 위치 기반
자동 기록이 실제로는 잘 안 맞는 상황까지 끌어안고 있어 제품 설명과
구현 모두 애매해지고 있었다.

## Q. 가설/가정 (한 문장)

운전 종료를 감지하면 확인 절차 없이 바로 위치와 시간을 자동
저장하고, 층·구역·사진 같은 세부 정보는 완전히 선택 사항으로
미루며, 서비스 범위를 "야외·지상 주차장"으로 명확히 좁히면 더
간결하고 신뢰가는 경험을 줄 수 있을 것이다.

## 한 일

- **자동 저장을 기본 동작으로 변경**: 운전 → 보행 전환이 감지되면
  확인 팝업 없이 바로 현재 위치(시뮬레이션상 정확도 오차 포함)와
  시간을 저장한다. 사용자가 원할 때 언제든 수동으로 다시 저장(갱신)
  하는 것도 계속 가능하다.
- **선택적 상세정보 입력**: 저장 성공 시 알림을 띄우고, 층수·구역·
  사진·메모는 그 알림이나 홈/상세 화면에서 원할 때만 추가하도록
  분리했다. 예전에는 이 정보들이 사실상 필수 입력 흐름이었다.
- **블루투스 제거**: 시뮬레이션에서 블루투스 등록/연결 절차를 모두
  없앴다. 기능적으로 차이가 없는데 시연만 복잡하게 만들어서, "운전
  → 보행 전환" 감지만 남기고 설정 화면에 "추후 지원 예정" 안내
  문구만 남겼다.
- **서비스 포지셔닝 조정**: "모든 주차장에서 정확한 위치를 찾는 앱"이
  아니라 "야외·지상 주차장에서 위치를 자동 기록하고 다시 찾아가는
  앱"으로 범위를 좁혔다. 저장 알림과 홈 화면에 오차(m) 표기, 지하·
  실내에서는 부정확할 수 있다는 안내 문구를 추가했다.
- **차량 위치 찾기 기능 추가**: 내 위치에서 차량까지의 거리·방향을
  나침반 형태로 보여주는 기능을 앱(홈/상세 화면)과 랜딩페이지 양쪽에
  추가했다. 랜딩페이지에는 목표 장소 목록(대형마트, 휴게소, 공영
  주차장, 아파트 지상 주차장 등)도 함께 정리했다.
- **자동 저장 on/off 설정**: 설정 화면에서 이 자동 저장 자체를 끌 수
  있게 했다. 끄면 운전→보행 전환을 감지해도 아무 것도 자동으로
  저장하지 않는다.

## 상태

- 위 변경 사항 모두 프로토타입 상에서 구현 완료.
- Playwright로 자동저장/수동저장/선택적 상세정보 추가/차량 위치
  찾기/자동저장 끄기 시나리오를 직접 구동해 정상 동작을 확인했다.
- 아직 실사용자 피드백은 받지 못한 상태.

## 다음에 확인할 것

- 확인 절차 없이 바로 자동 저장되는 방식이 사용자에게 안심되는지,
  아니면 불안하게 느껴지는지 (엉뚱한 곳에서 저장될까 봐 걱정되는지)
- 층·구역·사진을 나중에 선택적으로 추가하는 흐름이 자연스러운지
- 차량 위치 찾기(방향·거리 안내)가 실제로 도움이 될 것 같은지
- "야외·지상 주차장" 특화 포지셔닝과 정확도 안내 문구가 잘
  이해되는지, 지하주차장을 자주 쓰는 사용자에게는 어떻게 느껴지는지
