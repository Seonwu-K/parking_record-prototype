# 프로젝트 메모리

## 프로젝트 개요

"마지막 주차" — 주차 위치를 기록하고 빠르게 다시 찾을 수 있게
돕는 앱 프로토타입. 최종적으로는 네이티브 앱을 목표로 하지만,
현재 단계는 **프로토타이핑**이다. 지금은 실제 앱처럼 보이는
웹 화면에서, 앱을 쓰는 것처럼 시뮬레이션할 수 있는 웹사이트를
만들어 빠르게 검증하는 데 집중한다.

- 프로토타입: Gemini Canvas로 만든 `index.html` (참고용 초안)
- Next.js(App Router, TS, Tailwind)로 재구성 완료, Vercel에 배포되어 있음
- 저장소: 개인 계정(`origin`)에 우선 push, 추후 organization으로 이전 가능성 있음

## 사이트 구조 (2026-07-14 개편)

앱 체험 시뮬레이션 단일 페이지였던 구조를, 실제 서비스처럼 방문자를
맞이하고 체험 후 피드백까지 자연스럽게 이어지도록 개편했다. 이건
사용자 피드백이 아니라 자체 기획 결정이라 날짜별 로그에는 남기지
않고 여기에만 기록한다.

- `/` — 제품 랜딩페이지. 문제 정의, 핵심 기능 소개, "체험해보기" CTA
- `/simulate` — 기존에 메인이었던 스마트폰 시뮬레이션 프로토타입
  (`ParkingApp`). 상단 탭("홈" / "앱 체험해보기")으로 랜딩과 오간다
- `/feedback` — 체험 후기를 남기는 설문 페이지 (구글폼 스타일).
  문항은 임시 placeholder이며 추후 구체화 예정
- 시뮬레이션에서 주차 위치 저장(성공 화면 도달)을 완료하면 우측
  하단에 평가 유도 팝업이 뜨고, "평가 남기기"를 누르면 `/feedback`으로
  이동한다

## 매일 반복하는 사이클

1. 불편을 고른다
2. 가설을 세운다
3. 작은 프로토타입을 만든다
4. 사용자에게 보여주고 물어본다
5. 배운 것을 정리한다
6. 다음에 확인할 것을 정한다
